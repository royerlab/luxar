My Beautiful Host Page

This page mounts the Luxar viewer inside the box below. The page's serif font, beige background, and bulleted list should remain intact — that's the embeddability contract.

  • Importing luxar-viewer/styles.css must not change the host page's margins, fonts, or scrollbars.
  • Importing { LuxarApp } from 'luxar-viewer' must not patch the host page's console.*.
  • Calling app.dispose() must remove the viewer completely and leave the host page's state untouched.
