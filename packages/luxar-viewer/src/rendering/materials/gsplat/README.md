# GSplat Material

> Volumetric Gaussian-splat material — oriented instanced quads with full 3D covariance via Cholesky factors, perspective Jacobian projection to 2D screen-space covariance, and a shifted-Gaussian falloff with C⁰ continuity at truncation.

Each splat is rendered as an oriented quad sized from the eigendecomposition of the projected 2D covariance. The fragment shader evaluates the Mahalanobis distance from the projected centre, applies a shifted Gaussian (`exp(-½·r²) − C`) so the density is identically zero at the truncation radius, and then runs the per-node GOG (gain / offset / gamma) chain into the HDR target. Sum projection (emissive: additive / luminous / volumetric) integrates the Gaussian along the view ray; peak (2D-projected) projection (surfaces: max / normal / opaque — `usesPeakProjection`) writes the peak value.

Both backends ship side-by-side through the `ShaderSource` pattern documented in `../_shared/README.md` — `GSPLAT_SOURCE.webgl` provides the GLSL3 strings and `GSPLAT_SOURCE.webgpu` is the TSL `NodeMaterial` factory.

## Splat data storage (Phase 1 texture migration)

Per-splat data (`center`, the 6-stride `choleskyFactors`, `amplitude`, `color`) does **not** live in vertex attributes. It lives in an RGBA32F **splat texture** (`uSplatTex`, 4 texels/splat — layout authority in `../../element-texture-layout.ts`), fetched in the vertex stage via `texelFetch` (GLSL) / `textureLoad` (TSL). The only per-instance data is the ordering pair `aSortedIndex` / `aSortedIndexB` (Uint32): the draw-slot → storage-slot map, written as identity by every commit and permuted by the sort worker. It is DOUBLE-BUFFERED — a new ordering streams into the inactive buffer and the `uSortedIndexSlot` uniform flips once it is whole, so no frame samples a half-applied permutation (the pair is aliased onto one buffer until a node first sorts, so a commutative-mode node pays nothing). Consequences:

- **Materials are per node.** Each gsplat material binds its node's texture, so the material-manager LRU is bypassed for gsplats (`getGSplatMaterial` always creates). The commit rebinds `uSplatTex` on render + pick materials via `syncGSplatMaterialWithGeometry` (pool acquire may hand the node a different geometry+texture pair on growth/reuse).
- **Texture lifetime = geometry lifetime.** `attachSplatStorage` registers a geometry-`dispose` listener; every pool/fallback dispose site frees the texture with its geometry.
- **TSL texture-node lifecycle.** The TSL `texture()` node is factory-time bound, so `updateSplatTexture` rebuilds the graph on an identity change (exact mirror of the colormap-texture lifecycle) and no-ops otherwise.
- **GLSL fallback trap (load-bearing `int()`).** TSL types `textureSize()` as `uint` (WGSL convention) but GLSL's `textureSize` returns `int` — the width read is wrapped in `int(...)` or the generated GLSL fails to compile on the `forceWebGL` backend.

## Vertex pipeline

The vertex shader is the bulk of the work. Both backends implement the same sequence, prefixed by the splat-texture fetch prologue (step 0):

0. Fetch the splat's 4 texels by `aSortedIndex` and reconstruct `aCenter` / `aCholesky*` / `aAmplitude` / `aColor` as locals — zero changes downstream.
1. Transform centre to camera space; reject behind-camera splats (camera looks down `-Z`).
2. Rotate the 3D Cholesky to camera space using the top-left 3×3 of `modelViewMatrix`; compute `Σ_cam = L_cam · L_camᵀ`.
3. Apply two independent fades and combine via `min` (near-plane fade is perspective-only; coverage fade applies in both projections):
   - **Near-plane depth fade**: `smoothstep(uNearCull, 2·uNearCull, zDepth)` — principled fade to prevent the `1/z` Jacobian singularity near the camera. Scene-scale-aware via the per-scene `uNearCull` set by `updateCameraParams`.
   - **Screen-coverage fade**: `1 − smoothstep(0.5·maxExtent, maxExtent, projectedExtent)` — bounds projected splat size to `uMaxExtentFactor × max(viewportW, viewportH)`. Pairs with the quad extent clamp below; the fade is what masks the hard edges the clamp would otherwise produce.
4. Build the perspective Jacobian (`J0 = (fx/z, 0)`, `J1 = (0, fy/z)`, `J2 = (fx·x/z², fy·y/z²)`) or the orthographic Jacobian (depth-independent), branching on `uIsOrtho`.
5. Project covariance to 2D: `Σ_2D = J · Σ_cam · Jᵀ`, written out explicitly because TSL has no `mat3x2` type and GLSL benefits from the hand-rolled symmetry. Then add the **2D low-pass dilation** `uCov2DDilation` (default 0.3 px²) to the `Σ_2D` diagonal — the standard 3DGS anti-aliasing that guarantees every splat covers ≥ ~1px, so near-degenerate (edge-on/flat) splats render as a soft ellipse instead of a razor-thin sub-pixel spike. Diagonal only (off-diagonal would rotate/shear); applied before the guard/Cholesky/eigen so the fragment footprint and the quad stay consistent.
6. NaN/Inf guard on `Σ_2D` and `aAmplitude` — rejected splats route to `gl_Position = (0, 0, -2, 1)` (behind camera).
7. **Sum (ray-integral) projection** (`uProjectionMode == 0`, emissive modes additive/luminous/volumetric — runtime branch in GLSL / JS-conditional graph emission in TSL, see "Sum vs peak graph emission" below): explicit 3×3 cofactor expansion for `Σ_cam⁻¹`, then `sigmaRay = 1 / sqrt(rᵀ Σ_cam⁻¹ r)`, then amplitude boost `aAmplitude · sigmaRay · uRayIntegralFactor`. The inversion is **trace-normalized** (`Σn = Σ_cam / (trace/3)`, `sigmaRay = sqrt(s / quadN)`): `det(Σ)` is world-units⁶ and under/overflows float32 on tiny/huge-unit scenes (GPUs flush denormals to zero), so the determinant/quadratic floors act on O(1) normalized values — scale-free condition-number guards instead of absolute epsilons. **Peak (2D-projected) projection** (surface modes max / normal / opaque): amplitude is just `aAmplitude · nearFade`. Alpha-over is the surface model, so a splat's contribution is its projected-2D-Gaussian peak, NOT the emissive line-integral (whose boost would over-brighten and saturate the normal-mode coverage alpha to opaque).
8. Eigendecompose `Σ_2D` (symmetric 2×2 closed-form) → `lambda1`, `lambda2`, oriented `(majorAxis, minorAxis)`. Near-diagonal covariance picks the axis with larger variance.
9. Quad extent = `uTruncate · sqrt(lambda)`; clamp uniformly when `max(extent1, extent2) > maxExtentPx` so the rasterizer never shades oversized quads.
10. Project centre to screen pixels (ortho vs perspective branch); expand the quad in oriented screen space; convert to NDC; emit `gl_Position = (ndcXY, projectionMatrix·centerCam.z/w, 1)` so the depth buffer behaviour matches non-splat geometry.

The 2D Cholesky factorisation produced for the fragment shader is packed as `[invL00, L10, invL11]` so the fragment forward-substitution uses MUL instead of DIV.

## Fragment pipeline

The fragment shader is tight: pixel offset from `vCenterScreen`, forward substitute against the packed 2D Cholesky for `y = L⁻¹·d`, squared Mahalanobis `mahalSq = y₀² + y₁²`, **early discard** at `mahalSq > uTruncateSq`, then the shifted Gaussian `vAmplitude2D · uInvOneMinusC · max(exp(−½·mahalSq) − uShiftC, 0)`. A second early discard at `intensity < 1e-4` skips the per-node GOG chain for negligible contribution. After GOG, a third discard skips fully-clipped fragments — under `LUXAR_VOLUMETRIC` this zero-color discard also requires τ `< 1e-4` (a black splat still absorbs: a pure-ink occluder via gain → 0 must keep its optical depth). Output is `vec4(gammaColor · intensity · uOpacity, 1.0)` — alpha is `1.0` in every mode **except `normal` and `volumetric`**.

The alpha contract: alpha = `1.0` everywhere except the two sorted modes. In `'normal'` mode the shader (under the `LUXAR_NORMAL_PREMULT` define / the TSL factory's normal branch) emits a **premultiplied coverage alpha** `clamp(intensity · uOpacity, 0, 1)` paired with `getGSplatNormalBlendingState()`'s `ONE / ONE_MINUS_SRC_ALPHA` state — real semi-transparent compositing: the framebuffer behind a splat is revealed in proportion to coverage, and dim (HDR-faint) splats occlude proportionally little. In `'volumetric'` mode (under the `LUXAR_VOLUMETRIC` define / the TSL factory's volumetric branch) alpha is the **physical absorption** `1 − e^(−τ)` with `τ = uAbsorption · uOpacity · rayMass` (the sum-projected ray integral), and RGB carries the self-screened emission `finalColor · S(τ)`, `S(τ) = (1 − e^(−τ))/τ` — emission–absorption compositing (Max 1995) over the same `ONE / ONE_MINUS_SRC_ALPHA` state; κ = 0 gives α = 0, S = 1, bit-identical framebuffer RGB arithmetic to `additive` (dst-alpha accumulation differs; invisible on the alpha:false canvas). Consequences shared by both: sorted-mode gsplats never write depth (so they do **not** occlude additive layers behind them — the generic normal mode's `opacity ≥ 0.99` depth-write flip would let near-transparent splat skirts punch occlusion halos), and compositing is order-dependent — the `needsDepthSort` predicate (`normal` ∪ `volumetric`) gates the back-to-front depth sort (see `docs/guides/specs/GSPLAT_DEPTH_SORTING_SPEC.md` and `docs/guides/specs/VOLUMETRIC_BLENDING_SPEC.md`). The alpha=1 contract still matters for every OTHER mode: additive/luminous rely on `SrcAlpha` being the identity factor (that is what makes the shared `AdditiveBlending` state equal the linear One + One sum), and max compares premultiplied RGB contributions directly.

## Unified blending state across backends

Both wrappers' `applyBlendingMode` methods now draw from the SAME two sources of truth, so the GLSL and TSL paths are state-identical:

- **additive / luminous / max / opaque** → the shared `getCompleteBlendingState`. Additive/luminous are `AdditiveBlending` (`SrcAlpha + One`); because the shader emits `alpha = 1.0` in those modes, `SrcAlpha` is the identity factor and the result is exactly the linear `One + One` sum. (Historically the GLSL wrapper hand-rolled `CustomBlending + OneFactor` with a separate `MaxEquation` alpha channel to keep accumulated alpha finite for post-processing; that guard's only remaining consumer was the `raw-scene-hdr` capture path, which now sanitizes alpha at the readback boundary for every geometry type — see `post-processing/post-processing-manager/capture.ts` — so the divergence was deleted. Separate alpha-channel blend state also trips a `gl.getError()` flag under `WebGPURenderer`'s WebGL2 bridge, which is why the TSL wrapper never reproduced it.)
- **volumetric** → the shared `getCompleteBlendingState`'s own entry: `CustomBlending + AddEquation + One / OneMinusSrcAlpha`, `transparent: true`, `depthWrite: false` **unconditionally** (no `normalModeDepthWrite` coupling) — the same framebuffer state as `getGSplatNormalBlendingState()`; the semantic difference (absorption alpha vs coverage alpha) lives entirely in the fragment shader's `LUXAR_VOLUMETRIC` branch, not the blend state. Only gsplats implement the volumetric fragment math in phase 1; point/line materials intercept the mode and apply the **additive** state instead (the exact κ = 0 limit).
- **normal** → the gsplat-specific `getGSplatNormalBlendingState()`: `CustomBlending + AddEquation + One / OneMinusSrcAlpha` with a **symmetric** alpha channel (bridge-safe), `transparent: true`, `depthWrite: false`. Never expressed via `material.premultipliedAlpha`: on the TSL path `NodeMaterial.setup()` auto-injects an output RGB×alpha transform when that flag is set, which would double-premultiply a shader that already premultiplies.

Note: the HDR target's alpha channel accumulates unbounded under additive blending (an overdraw count, potentially HalfFloat-Inf on dense scenes) for ALL geometry types — points/lines emit real alpha over `SrcAlpha + One` too. Nothing on-screen consumes it (mega/bloom/FXAA read `.rgb` and force output alpha to 1.0); the capture sanitization covers the one path that exports it.

Both paths set `uProjectionMode` (0 = sum for the emissive modes additive/luminous/volumetric; 1 = peak for the surface modes max / normal / opaque — the `usesPeakProjection` predicate) so the vertex shader picks the correct projection. The surface → peak coupling is the principled one: max/normal/opaque composite surfaces, which want the projected 2D-Gaussian peak, whereas additive (and volumetric, whose τ is built from the same ray mass) stacks emission, which wants the ray-integral.

## Sum vs peak graph emission

The sum-projection branch carries the 3×3 cofactor expansion + `inversesqrt` — roughly 20-30 ops/vertex. The GLSL shader branches at runtime on `uProjectionMode` (warp-coherent uniform, GPU handles cheaply). TSL's `.select()` does **not** short-circuit — both branches would materialise — so `gsplatWebGPUFactory` JS-conditionally emits only the path the active blending mode uses (`usesPeakProjection(mode)` → peak, else → sum). The fragment **output branch** (alpha=1 vs normal's coverage alpha vs volumetric's emission–absorption) is likewise chosen at graph build time, so `GSplatTSLMaterial.applyBlendingMode` calls `rebuildGraph()` on `projectionChanged || outputBranchChanged`, where `outputBranchChanged` covers BOTH the `isNormalMode` and the `isVolumetricMode` crossings — the projection comparison uses the same `usesPeakProjection` predicate as the factory, so an emissive↔surface switch (e.g. additive→opaque) can never keep a stale graph, and an additive↔volumetric switch (which crosses neither `usesPeakProjection` nor `isNormalMode`) is caught by the `isVolumetricMode` term; non-crossing mode changes only flip `needsUpdate`.

`uProjectionMode` is still declared in `GSplatTSLNodes` and kept on the material (with `void uProjectionMode` in the factory) so `clone()` and runtime telemetry continue to work even when the live graph doesn't read it.

## Uniform reference

| Uniform                                          | Type        | Role                                                                                                                            |
| ------------------------------------------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `uResolution`                                    | `vec2`      | Viewport pixels (used by Jacobian, screen-coverage fade, oriented-quad NDC).                                                    |
| `uFx`, `uFy`                                     | `float`     | Focal lengths in pixels; set by `updateCameraParams` via `computeFocalLength(fov, height, isOrtho)`.                            |
| `uIsOrtho`                                       | `int`       | 0 = perspective, 1 = orthographic. Branches Jacobian, fades, and screen mapping.                                                |
| `uNearCull`                                      | `float`     | Near-fade start distance (perspective only).                                                                                    |
| `uMaxExtentFactor`                               | `float`     | Coverage fade + quad clamp threshold as a fraction of `max(width, height)`. Default 0.33.                                       |
| `uCov2DDilation`                                 | `float`     | 2D low-pass dilation added to the `Σ_2D` diagonal (px²; 3DGS anti-aliasing). Default 0.3 (`GSPLAT_COV2D_DILATION_DEFAULT`).     |
| `uTruncate`, `uTruncateSq`                       | `float`     | Truncation radius in sigmas and its square. Default 3.0.                                                                        |
| `uShiftC`, `uInvOneMinusC`                       | `float`     | Shifted-Gaussian boundary value `exp(−½·T²)` and the peak-preserving rescale `1/(1−C)`. Recomputed by `updateTruncationRadius`. |
| `uRayIntegralFactor`                             | `float`     | Shifted-Gaussian ray integral; computed by `computeRayIntegralFactor` in `math.ts`. ≈ 2.433 for `T = 3`.                        |
| `uProjectionMode`                                | `int`       | 0 = sum (ray-integral: additive/luminous/volumetric), 1 = peak (2D-projected: surface modes max/normal/opaque).                 |
| `uOpacity`, `uIntensity`, `uOffset`, `uInvGamma` | `float`     | Per-node opacity + GOG chain.                                                                                                   |
| `uAbsorption`                                    | `float`     | Absorption κ (≥ 0, default 1.0); read only under `LUXAR_VOLUMETRIC` (τ = κ·opacity·rayMass), inert in every other mode.         |
| `uColormapTex`, `uScalarMin`, `uScalarScale`     | conditional | Present only when `defines.USE_COLORMAP` is set; LUT lookup uses `aAmplitude` as the scalar (mirrors the GLSL path).            |

The `LUXAR_GAMMA_ONE` define (set by `updateGamma` when `gamma == 1.0 ± 1e-4`, the default) skips the per-fragment color `pow()` — `pow(x, 1) == x` — and the pre-LUT value `pow()` in colormap mode. Mirrors the Line/Point fast path (`isGammaOne` in `../_shared/uniform-helpers`). The TSL wrapper rebuilds its graph when the define toggles; the GLSL wrapper flips `needsUpdate`. The mode defines `LUXAR_NORMAL_PREMULT` and `LUXAR_VOLUMETRIC` (mutually exclusive, both managed by `applyBlendingMode`) select the fragment output branch — coverage alpha and emission–absorption respectively (see "The alpha contract" above).
