# luxar.gsplats.seeds.demos

Runnable demo scripts for seed generation methods.

## Demos

| Script | Description |
|--------|-------------|
| `demo_decomp_seeds_mitosis.py` | Compares grid, decomposition, and edge seeding methods on the scikit-image human mitosis dataset. Displays seed locations side-by-side in napari. |

## Running

```bash
hatch run python packages/luxar/src/luxar/gsplats/seeds/demos/demo_decomp_seeds_mitosis.py
```

Requires napari and scikit-image.
