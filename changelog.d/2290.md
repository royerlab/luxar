#### Bound eager line-loading memory

The viewer now admits eager line siblings by their declared vertex and segment working set as well as the existing eight-wide slot limit, using a bounded share of the measured heap and letting smaller siblings use available headroom without changing authored order. This prevents several million-element line nodes from overlapping their decode, projection, staging, and geometry allocations while preserving slot-only concurrency for other geometry types, and logs when admission waits or required vertex-count metadata is missing.
