#### Content-tiled flat fits publish merged quality metrics

Content-adaptive fits now score the merged flat reconstruction against the whole reference volume, for both sequential and parallel box drivers, using the same bounded-memory scorer as uniform tiling. When scoring cannot run — including an over-budget volume, a missing or mismatched reference, or the current `kind=partition` result — the fit says why even under `--quiet` and names the `gsplat compare` recourse instead of silently shipping an unscored archive.
