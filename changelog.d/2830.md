#### Add an opt-in rendered LOD acceptance bench

The viewer now has a Linux-Chromium visual A/B command that generates a deterministic
Points fixture, captures its coarsest and finest substitutive LOD levels at the same
camera, and checks image similarity, colour error, light conservation, and clipping drift
against recorded per-bench thresholds. The screenshot and scoring core is shared with
the existing WebGPU-vs-WebGL comparison script.
