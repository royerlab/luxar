#### Expose terminal dataset faults to embedded viewers

Embedded hosts can now subscribe to a `dataset-fault` event when an already-loaded archive becomes unable to update, or query the same app-scoped state with `getDatasetFault()` after a late subscription. An explicit retry clears the current fault; a recurring archive fault emits the event again.

Lazy LOD loads now escalate container-wide archive faults to the scene loader, showing the persistent fault notice and stopping retries for an archive that can no longer be read.
