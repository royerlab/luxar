#### Mesh LOD colour fidelity is pinned by value, not by flag

The ladder's colour test asserted only `has_colors`, so a coarse level that came
back black, clipped, or cast to another dtype set the flag exactly like a correct
one — every row of the `#1355` table would have passed. It now reads the colours
back through `LuxarScene` per level and checks the dtype, the shape, and the
values, across `uint8`, `uint16`, and float32 in both SDR and HDR ranges. (The
scalars ladder was already pinned by value.)

The gradient matters as much as the readback: the previous test coloured every
vertex the same, and the writer broadcasts a constant to a `(1, 3)` row, so it
never exercised per-cluster averaging at all. The three channels now carry
different values too, so a dropped or swapped channel cannot pass. A `(1, 3)`
broadcast row — the other shape the issue measured — now has its own ladder test.
