#### Mesh LOD colour fidelity is pinned by value, not by flag

The ladder tests asserted only `has_colors` / `has_scalars`, so a coarse level that
came back black, clipped, or cast to another dtype set the flag exactly like a
correct one — every row of the `#1355` table would have passed. They now read the
colours back through `LuxarScene` per level and check the dtype, the shape, and
the values, across `uint8`, `uint16`, and float32 in both SDR and HDR ranges.

The gradient matters as much as the readback: the previous test coloured every
vertex the same, and the writer broadcasts a constant to a `(1, 3)` row, so it
never exercised per-cluster averaging at all. A `(1, 3)` broadcast row — the other
shape the issue measured — now has its own ladder test.
