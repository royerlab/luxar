#### Foreground-weighted calibration for sparse volumes

`luxar gsplat cal` can now select K* with foreground-weighted held-out PSNR,
using a dependency-free Otsu foreground mask and recording the mask metadata in
`cal.json`. CLI tables and PDF reports follow the selected metric, while updated
guidance clarifies that gain-over-predict-zero selects the same K* as min-max
PSNR and directs sparse or deconvolved volumes to the weighted metric instead.
Intensity feature counting and content tiling now share the same dependency-free
Otsu threshold as calibration; installs with scikit-image are unchanged, while
plain `luxar[gsplats]` installs no longer treat every value above the floor as
foreground.
