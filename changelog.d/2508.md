#### A capture is no longer reported ready when a memory ceiling truncated it

Progressive refinement stops scene-wide once tracked residency reaches the
refinement byte ceiling, and the GPU buffer pool sheds pooled geometry —
levels the LOD registry demoted from active included — when it goes over its
VRAM byte budget. Either leaves a scene whose element counts are a property of
the run rather than of the store — `desi_galaxies` authors 9.75M points, of
which one layer's finest level alone is 446 MiB of the 512 MiB ceiling, so it
settles wherever the refinement order happened to land. Until now the only
signal was a single console warning, and `summarizeCaptureReadiness` reported
`ok: true` for such a scene, so every capture tool and A/B comparison
downstream believed the truncated counts.

`RefinementResidencyReporter` now records every refusal (distinct paths, plus
the first verdict's reason and byte figures) in addition to logging the first
one, and the GPU pool counts byte-budget evictions separately from ordinary LRU
recycling. Both surface on `__luxarDebug.getState()` — as
`refinementResidency` and `gpuPool.byteBudgetEvictions`, the latter finally
wiring up a `gpuPoolStats` provider that had been declared but never passed —
and `summarizeCaptureReadiness` refuses on either, naming the first refusal's
verdict, the resident and budget figures and the path that stopped first. Note
that a byte-budget eviction does not on its own prove rendered geometry was
lost, and does not fire at all when active bytes alone exceed the budget; it
says the pool's residency was decided by the machine, which is enough to make
the capture incomparable.

Both accumulate for the life of the scene loader with no reset: they answer "did
this happen at some point while this scene was loaded", not "is it true right
now", so a scene that stopped once and later refined fully is still refused —
refinement order is path-dependent, so that run settled on a composition the next
would not reproduce. Scope is the loader, not the page: an in-page dataset switch
builds a fresh loader, reporter and pool, so the next scene starts clean with no
reload.
