#### Warn when overlapping nodes have incompatible depth behavior

Scene finalization now reports overlapping geometry pairs where a defaulted
`additive` node ignores depth written by another layer, or where two
independently order-dependent transparent nodes have view-dependent cross-node
order. Explicit `additive` is treated as intentional X-ray rendering. The
diagnostic follows composed transforms, nD slider dimensions, viewer-compatible
scene-root semantics, inherited opacity and blending mode, and mutually
exclusive LOD branches. Partition parts and LOD chunks are named and deduplicated
as the author-facing node that owns them. To avoid pairwise noise from coarse
bounds, the order-dependent case requires containment and rolls up repeated hits
when either node was already reported; the additive/depth-writer case still uses
any positive spatial overlap. A scan of 56 materialized demo/example stores
produced one warning in `multiple_objects_example.luxar.zarr`. Existing rendering
defaults remain unchanged.
