#### Gaussian splats can carry exact categorical labels

Gaussian-splat leaves can now store one optional categorical class id per splat,
with an explicit id-to-name vocabulary. The channel uses the smallest exact
unsigned integer encoding and stays aligned through spatial ordering, filtering,
partitioning, flattening, migration, and re-encoding. Operations that would have
to invent a class-combination rule, such as merge-based coarsening, now refuse
the labeled input instead of silently corrupting its meaning.
