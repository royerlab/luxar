#### Correct the neuromast demo's Z anisotropy factor

The two-channel neuromast rebuild recipe now scales Z by the measured MetaMorph
voxel anisotropy, `0.25 / 0.1083 = 2.3084`, instead of the historical `2.5`,
which stretched the organ 8.3 % along the axial direction.

The archives pinned in the demo manifest were built with `2.5` and still carry
that stretch, so the scene the demo downloads is unchanged; correcting it needs
a re-fit and a re-upload to the record. An archive rebuilt from this recipe is
7.7 % shorter in Z than the pinned pair, which already differs from it in splat
count (the 2026-09 removal of the post-fit cull).
