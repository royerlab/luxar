#### Linear and geolog arrays now decode identically on every viewer route (#1849)

Large quantized ranges can be decoded in a worker while small ranges and worker
failures decode on the main thread. The main-thread `ArrayDecoder` duplicated
linear and geolog arithmetic with f64 metadata, so that routing choice changed
many output float32 bits within one encoded array. Both paths now call the same
f32-disciplined TypeScript kernels, and the Python-generated round-trip contract
records a second exact hash in viewer-kernel operation order instead of relaxing
cross-language coverage to a few approximate samples.
