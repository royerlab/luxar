#### The package now has a layering contract

`import-linter` declared three narrow rules and reported them kept across 1,026 files —
green, while the dependency graph carried ten mutually-cyclic subpackage pairs. There
was no contract describing which package may import which.

There is one now, and its order was chosen by measurement rather than assertion: every
ordering of the packages whose position was in question was scored by how many imports
point the wrong way up the stack, and the declared order is the minimum. Where two
orders tied, the tie was broken on what the imports mean — `gsplats` sits below `core`
and `io` because those consume the splat data model, not the other way round.

The 35 imports that still point the wrong way are listed as dated debt rather than
hidden. That list can only shrink: `import-linter` rejects an entry that no longer
matches anything, and a new `check-layer-order` gate pins 35 as the maximum, so a new
violation cannot be hidden by adding a matching ignore. The same gate re-checks that
the declared order is still the best available, so a structural change that argues
for a different architecture says so instead of quietly accumulating exceptions.
