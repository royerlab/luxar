#### Unbreak the viewer lint gate on dev

The scene-identity watchdog tests recorded probe URLs with `String(input)` on a
`RequestInfo | URL` parameter. That predates the type-aware ESLint rules, which
landed in a parallel branch, so the two met for the first time on dev and left
`typescript-tests` red for every branch cut afterwards. The stubs now resolve
the fetch input to its URL explicitly, which also keeps a `Request`-shaped call
readable in an assertion diff instead of printing `[object Object]`.
