#### Compiled point scenes can be read back through their authored structure

`LuxarScene.get_points(..., flatten=True)` now reconstructs the finest point
cloud from substitutive LOD, spatial partitions, and disjoint additive
increments. `get_point_array(..., flatten=True)` reads one field without
materializing unrelated shared arrays. The DESI scene repair path now uses this
supported reader surface instead of reaching into the encoding decoder.
