#### A pre-publish gate for the Zenodo records

`scripts/zenodo_prepublish_check.py` is read-only — it has no write and no publish
call — and checks the three depositions against the manifest immediately before a
human publishes them: every hosted file pinned at the size actually hosted, every
pin present on its record, no scratch or probe files left behind, the contents
table sized to the file count, and the size claims in the prose agreeing with the
files.

Each check exists because that mistake was made. The size audit alone found
**20 of 23** size claims in the record descriptions stale — they predated the
refit and rebuild campaign — including one that described a build that was
evaluated and rejected, down to its tile count and per-level splat totals.
