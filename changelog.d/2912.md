#### The view lives in the URL and travels as a JSON file

Re-windowing, recolouring or hiding layers and the camera you had framed used to be
lost on reload and impossible to hand to a colleague. The viewer now mirrors the
whole view state into the page's `#!<url-encoded JSON>` fragment, the way
Neuroglancer does — the camera pose plus only the layer fields that differ from the
scene's authored defaults — and applies it again when the scene loads, so the
address bar is a share link that opens to the same picture. Switching datasets
drops it, and an embedded viewer never touches its host page's URL (the mirror
follows the same `updateBrowserUrl` opt-in as the `?src=` rewrite).

The same document can be copied as formatted JSON, downloaded as `view-state.json`,
or loaded from a file through the Layers header's right-click menu; loading resets
every layer to its authored state first and moves the camera, so the result is
exactly the file. Its shape is published as
`packages/luxar-viewer/schemas/view-state.v1.schema.json`, and a unit test keeps the
schema and the runtime validator on the same field list.
