#### Element-capacity warnings are now filterable

Points, Lines, and Gaussian Splat nodes that exceed the conservative per-node
viewer capacity now emit the public `luxar.io.ElementCapacityWarning` while
retaining the existing arbol console diagnostic. Build scripts and tests can
therefore catch the condition or promote it to an error, and a corpus-wide demo
gate now rejects statically resolvable partition, compiler auto-partition, and
Gaussian Splat recipe budgets above the 4096-class GPU floor.
