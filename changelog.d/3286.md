#### A printable control-panel QR for exported kiosk folders

An exported scene with a control panel now prints a QR and panel address that
stay the same from one start of `serve.py` to the next. Off loopback the
relay requires a control token by default. It is generated on the first
start, saved in `control-token.txt` beside `serve.py` and carried in the URL
and the QR, so driving the display takes the URL and the token together.
Deleting the file issues a new token, and `luxar export --overwrite` keeps the
old one. With the relay on, a busy port is an error rather than a silent move
to another port. `--advertise-host NAME` puts a fixed name or reserved address
in the URLs while the server listens on every interface.

`serve.py` also writes `control-panel.pdf`, an A4 sheet with the QR at half the
page width, the address and a short explanation of how to use it, ready to
print and put up beside the display. `serve.py --auto-advance SECONDS` retimes
the scene's authored tour on site, without a rebuild (`0` turns it off).
