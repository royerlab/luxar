#### Gaia demo can build its catalog locally

The Gaia Milky Way demo now offers an explicit `--build-catalog` first-run path
that queries ESA Gaia DR3, prints the ESA/Gaia/DPAC acknowledgement, caches the
raw table for resume, and atomically promotes the correctly named zip archive.
`--recompute` replaces a cached catalog, and `astroquery` is now included in the
`demos` extra and `luxar demo deps` dependency table.
