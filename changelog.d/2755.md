#### Local batch workers stay on the selected CUDA devices

`batch-fit run` now maps each parent-visible CUDA index back through the
parent's `CUDA_VISIBLE_DEVICES` list before pinning a worker. Restricted runs no
longer jump to the same-numbered physical card, UUID and MIG tokens pass through
unchanged, and `--gpus cpu` explicitly hides CUDA from child fits.

Startup output reports each visible-index-to-token mapping with the device name.
Local planning also selects benchmark metadata from the GPUs that will execute
the tasks, so a nonzero `--gpus` selection no longer records GPU 0's name and
timing estimate in the manifest. On heterogeneous selections, the smallest
profiled card supplies the conservative tile and throughput profile while the
manifest records every selected model.
