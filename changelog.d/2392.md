#### Write the sliced-ladder rule where an author will meet it (#2392)

The playback defect in #2374 had five code fixes land against it and no
documentation at all: `CLAUDE.md` never mentioned it, the gsplat-pipeline skill
never mentioned `--target-ms` in a warning context, and there is no `docs/` page
on ladder authoring. The code now guards against the mistake in three places — the CLI
scales `--target-ms` by the slice count, the demo policy floors sliced first
rungs at an aggregate share, and `check-demo-ladders` fails a starved built store
— but nothing told an author *why* before they hit it.

The rule, now recorded in all four places an author is likely to be reading: on a
node the viewer slices, count elements per SLICE, not per node. An explicit
`-b stream:<c>` fixes an absolute first rung for the whole node while only one
hidden coordinate is on screen, so each slice receives part of that count;
Nexrad's explicit `stream:20000` ladder has p05 = 4 splats per played coordinate.
Before the CLI scaling fix, Drosophila's `--target-ms` resolved to a 20,833-splat
rung 0 for 500 timepoints; the measured slices had median = 45, p05 = 7, and min =
1, and playback rendered an empty frame. The CLI now scales `--target-ms` by the
observed slice count. `--n-lods L` gives an aggregate `1/L` share whose average is
slice-invariant, but its global prefix can still leave sparse slices below that
share, so long or non-uniform axes need the per-slice histogram checked.

`references/first-paint-requests.md` gains a "Sliced nodes" section carrying the
measured table (p05 rung-0 count per coordinate against what the deployed viewer
commits during playback, across five shipped demos), the occurring-combinations
definition of a stop, and a note that the gate reduces with the 5th percentile
rather than the maximum because a ladder starves at its sparsest slice. `SKILL.md`
and `CLAUDE.md` carry the short form, and `luxar-gsplat-edit` records that
`gsplat additive --n-lods 4` is the no-refit remedy for a store already built the
wrong way.
