#### The partial-extend tolerance is decided in one place again

`GEOMETRY_DESCRIPTORS` is the viewer's table of what each geometry kind needs
from the shared scene-loader machinery, and it exists specifically so a per-type
capability is a table entry rather than the presence of an `if`.
`applyPartialExtendTolerance` had escaped it: twelve call sites hardcoded the
boolean — the four node loaders, the four leaf handlers, the four LOD-refinement
loops — and only two read the table. Lines, the one kind that opts out, wrote
`false` in three separate places with three separate comments explaining why.

Nothing was visibly broken, which is the point: a wrong value there is not a
crash but a clipping result quietly too generous or too tight, on one geometry
type, in one code path. All twelve now read one table, which the descriptor also
sources from, and a test fails on any new hardcoded site.
