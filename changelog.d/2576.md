#### ESM Protein Stories: soap-bubble cluster shells, bubble framing, Biohub mark

The `esm3_protein_stories` kiosk demo now wraps each story's cluster in a
soap-bubble shell: the marker spheres use the physical mesh material (full
transmission, water IOR, iridescence and a little dispersion) lit by a
scene-captured environment, so the bubble reflects the map around it and bends
the map seen through it. Each story waypoint frames the bubble at the height of
the story panel, and a sparse cluster with a long tail is framed on its core
instead so the camera comes closer. The title is now just "ESM Protein Stories",
the dataset/model/license credit closes the Overview panel, and the generic
bottom-right caption gives way to the Biohub mark — a white-on-transparent PNG
bundled inside the package so the built store stays self-contained, blended with
`difference` so it reads on any background.

`Scene.add_image` accepts a `None` height (`size=(width, None)`), letting the
viewer size the image from its own aspect ratio, as `add_video` already did.
