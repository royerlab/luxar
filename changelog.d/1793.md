#### Relative NGFF level paths select the declared image array (#1793)

OME-Zarr image groups whose `multiscales.datasets[*].path` values use the legal
explicitly relative spelling (`"./0"`, `"./1"`) now resolve those declarations
before opening the zarr array. They therefore select the same full-resolution
level, axes, and voxel size as the equivalent `"0"`, `"1"` spelling instead of
falling back to a larger undeclared sibling and guessed axis roles.
