#### Restore the downloads helper package to built wheels

Built wheels once again include `luxar.demos._support.downloads`, so the
installed `luxar` command can import and run. An over-broad `.gitignore` rule
had silently removed that tracked subpackage from Hatchling's wheel inputs.

The packaging guard now checks tracked package files against the same root
`.gitignore` scope Hatchling uses, without false failures from Git negations or
developer-local exclusion files.
