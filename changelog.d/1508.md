#### Layers panel interaction depth: right-click menus, type-to-filter, and shared panel motion

The Layers panel gains right-click context menus, built on a new shared
menu widget (`ui/overlay-widgets/context-menu.ts`) with full menu ARIA,
roving keyboard focus, one side-flyout submenu level, and viewport
containment in both position and height. Rows offer Solo (toggle-restore:
re-Solo brings back the exact pre-solo visibility set), frame-camera-on-layer,
per-layer reset to authored state, copy-path, and Colormap/Blending radio
submenus plus apply-appearance-to-all; the eye button and panel header carry
visibility-verb menus. Shift+F10 / the ContextMenu key open the same menus
from the keyboard.

Layer-heavy scenes (more than eight layers) get a live name filter above the
list, and the help overlay gains shortcut search — both on a shared
`.luxar-panel-filter` recipe whose keystrokes never leak to viewer shortcuts.
Every floating surface now enters with the dataset browser's transform-only
scale-settle pop (shared `.luxar-panel-pop`, glass-safe), and the dataset
dialog contains Tab within itself while open, releasing the trap on hide and
close.

The control rail also moves above the three left-docked panels rather than
below them: its fractional resting opacity makes the rail a single stacking
context, so a docked panel stacked over it buried the hover tooltips that
reach rightward across it. It still sits below the modal tier, so dialogs
keep dimming it.
