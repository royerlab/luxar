#### Built demo stores are checked for their declared attribution

`hatch run check-scene-credits` now compares each built demo store with its
registry citation. It catches missing or malformed citation records and drift
in the attribution-bearing `short`, `doi`, and `license` fields, using Luxar's
shared zarr metadata reader so stale consolidated format-2 metadata cannot hide
what the viewer actually sees. The check is part of `check-static` and remains a
clean no-op when no demo stores have been built.

#### Unpublished Chromatrace work is absent from the public gallery

The `chromatrace_choir_umap` and `chromatrace_choir_umap_sequence` demos remain
available in the repository, but their gallery manifest entries are removed so
unpublished work is not presented on the public site.
