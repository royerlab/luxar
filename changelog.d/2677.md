#### Equal-energy additive ladders (`equi-energy:<n>`), and a batch of demo re-tunes

Additive ladders could be cut by equal count, by a bandwidth-derived geometric
schedule, or at explicit energy fractions. The new `equi-energy:<n>` breakpoints
vocabulary cuts `n` rungs at equal shares of cumulative perceptual energy along
the ladder's own contribution ordering, so the first rung is the few heaviest
elements and each later rung is fatter in count for the same light: first paint
is fast, and the rungs that take longest to arrive are the ones whose absence
shows least. Any increment above the shared 900K commit cap is split, so no
single commit blocks the main thread. GSplats resolve it against their
self-energy, Points against `luminance × radius³`, Lines against per-polyline
tube energy with the cap counted in vertices; the CLI accepts it wherever
`--breakpoints` is taken.

The same PR re-tunes several hosted demos from a review pass (cosmic web,
FlyWire, CELLxGENE, Tribolium, CT TotalSegmentator), gives the bird plumage demo
an explainer, re-ladders the CMU-1 pathology parts for a ~200 ms first paint,
and replaces the tractography demo's lifted-Gaussian coarse levels with
subsampled streamlines that carry labels on every level.
