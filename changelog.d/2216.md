#### A long dimension name no longer takes the whole slider row

A dimension slider's label is the dimension name out of the store, so a dataset
that spells its axes out at length could claim the entire row and leave no space
for the value beside it — the live position readout disappeared and the panel
grew a horizontal scrollbar. Each row now reserves a fixed width for its value
and ellipsizes an over-long name into whatever is left, with the full name kept
in a tooltip; a long value still cannot shrink the name. The panel's minimum
width also yields to a narrower window instead of hanging off both edges of it.
