#### Density guard: threshold knob, held-rung marker, audit record

`?densityCap=N` overrides the density guard's elements-per-pixel threshold for one session, for both the shader thinning ladder and the refinement rung gate, so a threshold sweep is one URL edit per arm; the Performance popover's Thinning row shows the cap in force. In the data monitor's scene graph a pending detail level the loader is deliberately holding back, either because the density guard deferred it at the current framing or because loading it would cross the residency ceiling, now shows a pause glyph instead of the streaming hourglass, with the reason in its tooltip, and the header counts such nodes as `held` rather than `refining`. The September 2026 viewer performance audit that drove these changes is preserved under `docs/guides/developer/`.
