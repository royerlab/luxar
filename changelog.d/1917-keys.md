#### Per-element `keys=`, so a link can be built from an id the tooltip does not show (#1917)

The click actions added alongside this substitute the hover vocabulary into a
URL, which works only when the visible label IS the linkable id. Across the demo
corpus it almost never is. Of the 27 demos that pass `labels=`, essentially all
build composite prose — `"P04637 · DNA-binding cluster"`,
`"Blinding Lights — The Weeknd (pop)"` — and in four of them the id is not in
the label at all, because it was never fetched. A template over `{hover_label}`
would produce a percent-encoded blob of the whole sentence.

So there is now a second per-element string channel. `labels` stays what a
reader sees; `keys` is what a machine reads:

```python
scene.add_points(
    "proteins", positions,
    labels=[f"{acc} · {cluster}" for acc, cluster in ...],   # unchanged, readable
    keys=accessions,                                          # "P04637"
    link="https://www.uniprot.org/uniprotkb/{hover_key}/entry",
)
```

It is stored as a CSR pair (`key_offsets` / `key_bytes`, flagged by
`has_keys`) — the same structure as labels, written by the same serializer with
a channel parameter rather than a near-copy of it, and read by the same viewer
loader constructed on the `'keys'` channel. That sharing is deliberate: keys
follow the same spatial permutation as labels (a key must stay paired with its
element), the same all-or-nothing rule across an additive ladder, the same
per-`part_<i>` slicing under a partition, and the same union-CSR-on-the-parent
placement for a ladder. Anything that treats them differently would be a bug,
so the code cannot express the difference.

The two channels are otherwise independent: a node may carry either, both or
neither, and a `link` built purely from `{hover_index}` needs no strings at all.
Keys are also much cheaper than the obvious alternative of storing a whole URL
per element — a six-character accession is ~7 bytes against ~45, and the viewer
decodes the entire CSR into memory on first hover, so a 3M-element scene would
otherwise hold hundreds of MB of near-identical prefixes.

Eleven demos adopt it: arXiv embeddings, CAFA5 and ESM3 proteins, Spotify tracks,
earthquakes, FlyWire, CAIDA, HuRI, asteroids, Tabula Sapiens, and the Gaia
landmarks. Each keeps readable hover prose while its bare identifier drives the
link/copy template; demos with missing or synthetic identifiers suppress the
link instead of offering a broken destination.

Two smaller fixes fell out of the threading. The ladder writers requested each
level's spatial permutation only when the ladder was *labelled*, so a keys-only
ladder asked for a union with zero permutations; they now request it when either
channel is present. And the gsplats writer imported its string validator inside
the `if labels is not None:` branch, which left the keys check referencing an
unbound name — the import is hoisted to cover both.
