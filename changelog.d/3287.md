#### Secure control relay defaults for `luxar serve`

`luxar serve --control` now generates a fresh token for each non-loopback run and prints it in the viewer and panel URLs. Existing network clients that connect without a token must pass the printed token, set `--control-token`, or explicitly opt out with `--no-control-token`. `--advertise-host` puts a fixed hostname or IP in those URLs while retaining the bind address and busy-port fallback.
