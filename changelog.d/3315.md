#### Native launcher control URLs remain available after Finder launch

When remote control is enabled off loopback, the native launcher now generates and saves a control token by default. It writes the panel URL beside the app, or under per-user state storage when the app's parent is read-only, so it can be retrieved without terminal output. Programmatic clients must pass the token from `<app>.control-token.txt` (or the printed fallback path) when connecting off loopback. `LUXAR_LAUNCHER_ADVERTISE_HOST` chooses the URL hostname, and `LUXAR_LAUNCHER_PORT` can keep the port stable across launches. Operators who deliberately want an open relay can set `LUXAR_LAUNCHER_CONTROL_TOKEN=off` or `LUXAR_LAUNCHER_NO_CONTROL_TOKEN=1`.
