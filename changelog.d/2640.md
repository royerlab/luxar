#### Silent accelerator probes report failures without losing fallbacks

Slurm and CUDA environment probes still fall back when optional tools or metadata are absent, but an available probe that breaks now emits one warning with the exception type and message instead of failing into silence. The defect-rule lint ratchet now also covers Ruff's BLE rules, so new blind exception handlers cannot reintroduce the same failure mode while existing debt remains explicitly baselined.
