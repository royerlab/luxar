#### Two E2E specs that #2494 exposed rather than broke

`test-fixtures-rendering.spec.ts`'s "should detect and report console errors"
navigates to a dataset that does not exist, which is the whole premise of the
test. It used to pass because the viewer quietly opened the dataset browser
instead; since the URL-suffix short-circuit the viewer honestly attempts the
load and logs four errors for the failure, and the fixture's automatic
console-error gate failed the teardown even though every assertion in the body
passed. The test now carries the fixture's per-spec `ALLOW_CONSOLE_ERRORS`
annotation. Not a new entry in `DEFAULT_ALLOWED_CONSOLE_ERRORS`: "Failed to load
scene" is the most important error the viewer can log, and forgiving it there
would blind the sixty-odd specs that share the fixture. The test also counted
warnings as errors — once in its page-console listener and again when tallying
the interceptor's buckets — so a single unrelated warning could satisfy it on
its own. The verdict now needs a genuine error from one side or the other, and
the warning counts stay in the diagnostic output.

`worker-wasm-integration.spec.ts` asserted that `DataWorker ready` appears in
the in-page console buffer. That line is logged from inside the data worker, and
the interceptor only patches the main-thread console, so it could never appear
there — the assertion sat behind an `if (hasWorkers)` guard that had always been
false. Moving pool creation to an eager warm-up at scene load put
`Worker N/M ready` in the buffer, flipped the guard true, and the dead assertion
finally ran. It now waits unconditionally for `Worker pool ready with N
worker(s)`, which is logged on the main thread and only after a pool comes up
with at least one worker. The test is renamed to what it verifies: neither
assertion ever established that a query was *offloaded*, which would need a
worker-served-query counter on the debug interface. The redundant sibling
"should create worker pool successfully" — same dataset, same probe, same final
assertion, same vacuous guard — is dropped.
