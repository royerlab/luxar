#### `image_labels` on a `substitutive_lod=` wrapper is checked before anything writes (#1491)

`scene.add_points("p", positions, image_labels=[...], substitutive_lod=True)` with
a wrong-length `image_labels` used to be refused only from deep inside the finest
child's own write — after every coarse gsplat level, and after that same child's
positions, colors, radii, sharpness, scalars and text labels, were already on
disk. The result was not a childless or truncated ladder: it was a complete,
fully loadable `kind=lod` group at every level, silently missing only the image
labels the caller actually asked for — harder to notice than a missing level, not
easier, since nothing about the store looked wrong. `image_labels` never fit the
per-part slicer the rest of this gate (#1437/#1446) relies on, since it is
forwarded only to the finest child, so it needed its own check. The length
(dense list) / index-bounds (sparse dict) validation is now hoisted out of
`write_image_labels_csr` into a standalone, pure function that both the
Points/Lines `substitutive_lod=` pre-split gate and every flat writer
(`write_points`, `write_lines`, `write_mesh`, `write_gsplats`) run before the
group is created. Mesh gained the same fix for the same reason on its own
decimation ladder.

A right-length list with one wrong-typed entry (an `int` where an image was
expected) strands identically, so the TYPE dispatch that used to live only in
the blob-encoding step was split out too and is now checked pre-write alongside
the length/index gate — one implementation, shared by both callers. That
dispatch also validates an `ndarray` entry's shape (`(H,W)` / `(H,W,3)` /
`(H,W,4)`) eagerly, since that costs nothing a type check does not already
cost; a mis-shaped array used to strand the same way a mistyped entry did.

Two narrower cases of the same strand went with it. A sparse key that is in
range but not a real integer index (`{1.5: blob}`, or a `np.float64` from an
arithmetic slip) used to clear the bounds check and then fail on the writer's
own list subscript, post-write; keys are now checked for integer-index
semantics (numpy integers still pass) alongside their bounds. And a dense
`image_labels` that can only be iterated ONCE is now refused up front with a
pointer to `list(...)`: a pre-write gate has to walk it to validate it, so
accepting one would leave the writer an exhausted iterator and stamp an
all-empty image CSR.

Separately, a `partition=` / `substitutive_lod=` split that recurses into the
same adder for a synthesised child (`part_0`, a decimated mesh `child_3`) used to
report a doubly-nested message naming that internal node — `Could not add points
'p': Could not add points 'child_3': ...` — rather than the node the caller
passed. The four adders now un-nest a same-geometry inner failure before
re-raising, so the message matches what the flat write would say for the same
input. A cross-geometry inner failure (the Points/Lines ladder's coarse children
are lifted `gsplats` nodes) is left alone on purpose, since collapsing it would
misattribute a different geometry's fault — including attributes the outer
geometry does not even recognise — to the wrong one.
