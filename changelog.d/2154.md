#### Grafted legacy partitions recover exact draw ordering

When a Gaussian-splat partition has no stored `bsp_tree`, scene grafting now
reconstructs split planes from the parts' center bounds and uses them only when
they exactly separate every part. Older and rebuilt partition archives therefore
keep stable back-to-front ordering for `normal` and `volumetric` blending without
rewriting the source store. Overlapping or interlocking parts still use the
existing centroid fallback rather than receiving an invented tree.
