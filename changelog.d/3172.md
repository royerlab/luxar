#### WebGPU is the default on Linux with Chromium and an NVIDIA GPU

WebGPU's cold load is now within 0.15 s of WebGL on both acceptance machines: the hosted `cold_zip_mixed` first frame is 70.6 ms behind WebGL on an RTX 3070 (Linux, Vulkan) and 57.7 ms behind on an M4 Max. Large depth-sorted scenes, the other condition, no longer cost more CPU on WebGPU now that it re-sorts on the GPU (#3162). With both met, the measured Linux + Chromium + NVIDIA row moves from the staged table into the active platform policy and those sessions now default to WebGPU, where it was 2-9% faster in GPU time on every heavy case. Every other platform keeps WebGL: macOS with an Apple GPU meets the cold-load target but stays off because WebGPU is still slower in GPU time there (#3224). `?renderer=webgl` and Settings › Advanced › Renderer still override the default.
