#### Bound automatic local Gaussian-splat worker concurrency

`gsplat fit -j auto` and `gsplat batch-fit run --jobs-per-gpu auto` now account
for fixed CUDA-process overhead and apply host RAM, CPU-count, and eight-worker
host caps instead of dividing VRAM by tile bytes alone. Multi-GPU runs share the
host-wide budget, and both commands report the resource that limited the resolved
worker count before fitting starts.
