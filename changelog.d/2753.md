#### Bound automatic local Gaussian-splat worker concurrency

`gsplat fit -j auto` and `gsplat batch-fit run --jobs-per-gpu auto` now account
for fixed CUDA-process overhead and apply host RAM, affinity-aware CPU-thread,
and configurable host caps instead of dividing VRAM by tile bytes alone.
Multi-GPU runs preserve every selected card while sharing the host-wide budget,
and both commands report the resource that limited the resolved worker count.
Set `LUXAR_AUTO_WORKER_HARD_CAP` to override the default eight-worker cap.
