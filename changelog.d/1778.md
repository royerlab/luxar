#### Denoised GSplat batches use the data basis they fit

Tiled normalization ranges and deferred batch background floors now resolve on the denoised intensity basis where possible, so every tile uses the same scale and pedestal as the data it actually fits. Uniform batches also report and reject a whole timepoint/channel slice when an applied floor leaves every spatial tile empty instead of silently dropping that slice from the merge.

For local on-the-fly percentile floors, the deferred resolver calibrates one NLM strength per selected channel and pins those same values into the fit workers so the shared floor and fitted data stay on the same basis. Non-deferred `auto` runs continue to self-calibrate per worker.
