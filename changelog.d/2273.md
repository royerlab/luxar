#### The documentation site is now linked from the README

`https://royerlab.github.io/luxar/` has been built on every promoted `main` for
some time, is publicly reachable, and serves the tutorials, guides, format
specs and the generated Python and TypeScript API reference — but nothing a
reader would ever open pointed at it. The README, both package READMEs and
`CONTRIBUTING.md` mentioned it zero times between them; the single occurrence
in the published documentation sat in `docs/index.rst`, which is only visible
once you are already on the site. The README's own "API Reference" is an inline
cheat-sheet, and the nav bar entry of that name is an anchor to it, so the
generated reference had no route in either.

The site is now linked from the API Reference section, the first row of the
Documentation table and an explicit `Docs Site` nav entry, alongside new rows
for the Viewer Guide and the CLI Reference — two sections that ship on the site
and had no README row at all.
