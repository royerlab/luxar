#### Make constrained GPU residency budgets bind

The shared GPU buffer-pool and LOD-retention byte budget no longer clamps a
measured small-device value up to 512 MB, where stranded growth buffers could
remain below the eviction threshold forever. Twenty-five percent of
`navigator.deviceMemory` now has only a 2 GB ceiling; 512 MB is used solely when
no memory signal exists.

An explicit `?cacheBudgetMB=` value (including the native launcher's
`LUXAR_CACHE_BUDGET_MB` setting) also supplies one third of the cache pool as
an automatic GPU residency signal. Without `navigator.deviceMemory` it replaces
the 512 MB fallback in either direction, so the launcher's 2048 MiB default
raises the GPU budget from 512 to 716 MB while smaller values constrain it.
Measured JS heaps at or below 1 GiB also constrain the budget because pooled
geometry retains CPU-side arrays. Roomier Chromium tiers are ignored: their
eager-loader working-set ceiling would otherwise cut a roomy desktop's default
GPU budget from 2 GB to at most 512 MiB.
