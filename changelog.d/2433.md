#### Make constrained GPU residency budgets bind

The shared GPU buffer-pool and LOD-retention byte budget no longer clamps a
measured small-device value up to 512 MB, where stranded growth buffers could
remain below the eviction threshold forever. Twenty-five percent of
`navigator.deviceMemory` now has only a 2 GB ceiling; 512 MB is used solely when
no memory signal exists.

An explicit `?cacheBudgetMB=` value (including the native launcher's
`LUXAR_CACHE_BUDGET_MB` setting) also supplies the cache pool's implied
non-cache remainder as an automatic GPU residency signal. It replaces the
heap-derived remainder in either direction, so the launcher's 2048 MiB default
resolves to 1432 MB while smaller values constrain it. Measurable Chromium heap
tiers use the same remainder derivation, allowing roomy desktops to scale past
the eager loader's unrelated 512 MiB cap up to the existing 2 GB ceiling.
