#### Rebuild demo scenes after writer changes

The four cached demos that carry builder fingerprints now include Luxar's production
Python sources and Zarr writer environment in that stamp, so encoder, store-writer, and
format changes invalidate scenes produced by older code instead of silently reusing
incompatible data.
Playwright now applies the same production-source freshness gate to its generated
viewer fixtures instead of checking only that fixture directories exist, and
`make test-e2e` repairs stale or incomplete fixture artifacts before running.
Example datasets and demos now share the same production-source fingerprint helper;
the next `make run-examples` rebuilds examples stamped by the older implementation.
