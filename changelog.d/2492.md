#### Complexity ratchet fails closed on Ruff scan drift

The C901 baseline now fingerprints Ruff's resolved settings, rejects nested
Ruff configurations, and verifies that every existing baselined file remains in
Ruff's scan set. Configuration edits and partial subtree drops therefore fail
the gate instead of being reported as paid-down complexity debt; both Ruff
ratchets share the same trust guards so their protections cannot silently drift.
