#### Existing LOD stores can be re-anchored without rebuilding

`luxar restamp-lod --anchor <fraction>` now explicitly re-derives whole-object
`screen-area` ladders that the migration-only command previously skipped as
already current, and sets the same requested anchor on legacy whole-object
ladders migrated in that pass. Thresholds are rebuilt from the stored level
count, the per-group old→new audit prints the numeric anchor, the
`--dry-run`/`--group` controls remain intact, and partition-bound ladders keep
their fills-screen `1.0` anchor. Repeating an anchor that is already stored
remains a true no-op, including `content_hash`.
