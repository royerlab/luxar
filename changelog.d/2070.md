#### Restored demo links and robust thin-volume seeding

Three demo link paths are corrected: arXiv restores DOI links lost to a stale
cache contract, ESM3 legacy caches gain useful protein-name searches, and
Cosmicflows gains per-galaxy NED links. CAFA5 synthetic stand-ins remain
deliberately unlinked because neither their generated ids nor generic cluster
labels identify a UniProt record.

The arXiv/bioRxiv/medRxiv landscape was the clearest case. It has always
intended to link each paper to `https://doi.org/<doi>`, gated on ids being
present in its cached bundle. `_compute_bundle` gained that `ids` field without
the cache version being bumped, so every warm cache kept serving id-less
bundles, `have_ids` stayed false forever, and the DOI links were never written —
on any machine whose cache predated the field. The version is now 4, which
invalidates those bundles and restores real DOIs.

The ESM3 landscape preserves old metadata caches without accessions by linking
through a clean protein-name search. CAFA5 synthetic stand-ins remain unlinked
instead of authoring searches that cannot resolve.

Cosmicflows/Laniakea gets a destination for the first time. Its hover label is
the basin of attraction a galaxy flows into — a property shared by tens of
thousands of galaxies, so searching it resolves nothing. The Principal Galaxies
Catalogue number was already being read from the source table and then
discarded; it is now carried through `GalaxyData` under the same spatial mask as
every other per-galaxy array, and each galaxy links to its NED object page.

Gaussian-splat fitting also handles thin anisotropic volumes whose first uniform
fallback grid is empty. The fallback now continues to a denser grid instead of
passing a malformed point array to the spatial query and crashing late in a fit.
