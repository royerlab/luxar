#### A demo's local refit no longer erases itself on every launch

A gsplat demo whose hosted data was unreachable — an unpublished Zenodo record
and no `git lfs pull` — fell back to fitting locally and cached the result at
`~/.cache/luxar/<dataset>/<file>`, which is byte for byte the path the manifest
fetch resolves for that entry. On the next launch `ensure_dataset` checksummed
it against the manifest, found (inevitably) that a local fit does not match the
hosted file's sha256, quarantined it as `.corrupt`, and raised — so the demo
refit from scratch, every single time, leaving another quarantined file behind.
The "one-time; result is cached" message was never true, and for the cryo-EM
capsid it cost about eleven minutes a launch.

Locally computed artifacts now live in their own namespace inside the same cache
directory, `~/.cache/luxar/<dataset>/local/<file>`, resolved by the new
`luxar.utils.data_fetch.local_fit_path`. The fetch never looks there, so nothing
hashes it, quarantines it or overwrites it. Its companion
`load_local_fit_gsplats` reads that namespace back — returning `None`, rather
than raising, when a file is missing or unreadable, since the only recovery for
bytes with no checksum and no remote is the refit the caller can already do. The
one failure it does raise on is a multi-part store, which has no flat
`GSplatData` form at all: a rebuild would write the same unloadable shape and
refit on every launch, which is the very symptom being fixed. A demo that
publishes its own `LOCAL_FIT` constant reads through the path-based
`load_local_fit_gsplats_at` instead, so the constant its refit WRITES through is
also the one the door reads — the two must not be able to drift apart.
Every affected demo now consults it after the manifest fetch comes up empty and
before refitting, so the refit really is one-time; the eleven demos that used to
write over the manifest's paths (cryo-EM virus, CT TotalSegmentator and its
labels sidecar, Milky Way dust, DAPI nuclei, OpenCell MAP4, cells3d, organoid
multichannel, both kidney demos, CMU-1 pathology, and the Visible Human head)
were migrated together. `luxar demo cache clear` now classifies anything under
`local/` as a computed artifact, so `--no-computed` spares these refits instead
of sweeping them away as if they were re-downloadable files, and labels cache
entries by their path relative to the cache dir so `local/x.zip` is
distinguishable from the fetched `x.zip` beside it. The classification keys on
the `local/` path alone: a demo that still writes an expensive artifact straight
into its cache dir (the NEXRAD per-frame fits, the C. elegans preprocessed
frames) is still counted as a download, which is deliberate — those names
collide with no pinned manifest entry, so they were never exposed to the
quarantine this change is about.

The nine demos that fall back to a local fit when the fetch comes up empty catch
the new `DatasetUnavailable` rather than a bare `FileNotFoundError`. Only one
condition means "these bytes are not obtainable from anywhere yet", and only that
one may be answered with a multi-minute refit; an unknown requested file name, a
missing packaged manifest and an in-repo copy that fails its pinned sha256 are
faults, and now propagate instead of being disguised as a routine rebuild.

An AST gate over every `demo_*.py` keeps the boundary: a demo that hands a
`~/.cache/luxar/<zenodo dataset>/<pinned file>` path to anything but a known
reader now fails the test suite, with the shapes the demos actually use
(a module-level constant join, an f-string built in a per-channel loop, an
indexed file list, a sidecar written by a demo-local helper, a second name the
path is laundered through, a write through a method on the path itself) each
covered by its own self-test. It resolves the cache dir by four spellings, not
one — the literal `Path.home()` chain plus a join onto `DEMO_CACHE_ROOT` /
`_DEFAULT_CACHE_ROOT`, directly or through another name — and, crucially, keys on
the DATASET NAME rather than the path spelling: a pinned file name joined to a
directory the analysis cannot identify is reported as a blind spot instead of
passing green, so a spelling nobody has thought of fails loudly rather than
silently. Verified by running the analysis over the eleven pre-fix sources, where
it fires on all eleven.
