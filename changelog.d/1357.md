#### `luxar mesh lod` names what it leaves behind (#1357)

The command reads a scene, picks one mesh node, and writes a BRAND-NEW scene
holding only that node's ladder — so everything else in the source is gone, and
until now it went without a word. A scene of one mesh plus a points cloud came
back as the ladder alone; the mesh's own per-vertex `labels` / `image_labels`
disappeared too (`MeshData` has no field for them, so the round trip cannot read
what it would have to write); and a mesh nested under a group with a transform on
it landed somewhere else entirely, because only the LEAF's attrs are forwarded
while the group's are inherited in the source and absent in the output.

The nodes still cannot be carried — there is nowhere in a single-ladder output
scene for them to go — but they are now REPORTED, by name, before anything is
written. Four categories: every other node (points / lines / gsplats / meshes /
groups, and user-authored overlays), each ancestor group whose inherited
placement or compositing is genuinely lost, the picked mesh's label channels, and
nothing else. Refusing outright was the alternative and is worse: it would leave a
multi-node scene with no way to build a ladder at all.

"Genuinely lost" is the load-bearing word in the ancestor line. Gating on mere
presence of a compositing key fires on the command's own output — every mesh leaf
carries `opacity` / `gamma` / `intensity` / `absorption` at 1.0 and `offset` at
0.0, and the ladder wrapper inherits those neutral values — so re-laddering a
level of an existing ladder would warn about five keys while losing none. A key is
reported only when it can actually change the picture: a non-neutral scalar, a
non-identity `transform` / `nd_transform`, a `blending_mode` neither the leaf nor a
nearer group already overrides (nearest setter wins), or a `layer` / `visible` away
from its own default. `join` never counts, since `add_mesh` refuses it in the first
place.

The warnings sit after every validator that can still abort the run and before
the destructive rewrite of the output path — announcing a drop and then erroring
out was its own small lie. A large partition collapses to one counted line per
parent rather than one line per sibling; the count is always the full one, never
a silent truncation.
