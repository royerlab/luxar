#### Gallery staleness report shows committed media size margins

`make check-gallery-staleness` now reports each committed README WebP/WebM size,
including the real byte count from Git LFS pointer metadata. It flags files at
the 20 MiB warning and 25 MiB limit shelves borrowed from the gallery capture
size guard (#2263), then prints the informational corpus total and five largest
files without turning the report into a gate.
