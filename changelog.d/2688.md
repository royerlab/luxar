#### Add an opt-in replacement-LOD bias

The viewer now accepts `?lodBias=<positive number>` and matching app/layer
options for A/B testing finer or coarser replacement-LOD selection without
rewriting stored thresholds. The value is defined in screen-area units: `2`
advances one occupancy-halved level, while legacy diagonal-coverage ladders
receive its square root so both selector types move by the same area factor.

The neutral default remains `1`. Finite screen-area coverage tops out at `1`,
so a value below `1` makes a partition-anchored finest level unreachable and a
value below `0.5` does the same for a whole-object finest level; near-plane
saturation still selects the finest level.
