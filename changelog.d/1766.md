#### Batch-fit tasks now read the volumes their plan names

A flat batch channel index is now decoded across every channel-like axis when
`--axes` names layouts such as `camera,time,channel,z,y,x`, instead of applying the
same index to both camera and channel. Batch planning also mirrors the positional
loader's singleton-axis squeeze, so thin 2D timelapses build tile grids and stacked
time barriers in the dimensionality their fit workers actually emit.
