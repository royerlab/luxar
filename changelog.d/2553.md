#### CLI tracebacks are opt-in for interactive commands

Interactive `luxar gsplat` commands now report a concise error by default instead
of attaching a Python traceback to routine failures. Set `LUXAR_TRACEBACK=1` when
re-running a command to see the original traceback. The long-running fit and batch
entry points still print tracebacks unconditionally so unattended GPU and Slurm
logs remain useful for post-mortem diagnosis.

Fatal error lines also fall back to stderr when process-wide arbol verbosity hides
normal narration, preventing a silent exit 1.
