#### Viewer CI reports every gate and coverage erosion

The viewer merge gate now runs every static and coverage check before reporting
ordinary failures together, while still stopping immediately when a subprocess
is killed. Local runs can retain fail-fast behavior with `check:ci -- --bail`.

Coverage floors now carry keyed recorded measurements with a fail-closed shape
check. The guard surfaces meaningful movement in either direction as GitHub
Actions annotations and can print a paste-ready recorded-baseline block with
`check:coverage-slack -- --print`.
