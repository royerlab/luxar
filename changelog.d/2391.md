#### A default composed ladder can no longer be sized without knowing the slice count (#2391)

`default_composed_additive_lod()` took no arguments. It sizes a substitutive
level's default first rung from a ~200 ms whole-node download budget, but the
viewer draws one hidden coordinate at a time, so on a sliced node that rung
arrives divided by the slice count — the mechanism behind #2374, where a
500-timepoint gsplat leaf painted 42 splats of a 166,443-splat frame. Its caller
had no positions and no scene either, so the information was not merely unused:
it was never plumbed to the layer that needed it.

Four places in the tree size a first rung. The CLI scales by slice count, the
demo policy applies a share floor, and the built-store gate catches the outcome.
This was the fourth, and the only one that could not be protected — a function
taking no arguments cannot be told the one fact that decides whether its answer
is right.

`elements` and `slices` are now required keywords on
`default_composed_additive_lod` and `compose_additive_under_substitutive`, so a
caller supplies both deliberately. The Points and Lines adders derive the slice
count from the new
`resident_slice_count`, which returns 1 whenever the positions do not align 1:1
with the scene dims — under-counting is the safe direction, reproducing the
historical whole-node sizing rather than inventing a divisor from a mis-mapped
column. Sliced defaults use the same 12.5% resident-share floor as demo
authoring, derived independently for every substitutive level and spatial
partition part, and reject a leaf whose resolved ladder would emit an increment
above the 900,000-element commit ceiling. This avoids both multiplying the byte
budget until it swallows the finest node and reusing the finest-node floor where
it would swallow a smaller child. Unsliced sizing remains 39,062 elements.

`hidden_coordinate_count` counts distinct *occurring* combinations across all
hidden columns: not the product of per-axis cardinality (`biodiversity_planetary_scale`
is 126 populated of 140) and not the declared `Dimension` range
(`drosophila_embryogenesis` declares 500 timepoints, its coarsest rung carries
data at 499). A coordinate holding no elements costs no bytes and divides no
rung.

The hole was latent rather than active — no built demo reaches this path with
hidden dimensions, and `slices=1` reproduces the previous value exactly, so
unsliced output is byte-identical. What the change buys is that the next caller
cannot reintroduce it.
