#### Make nD keyboard dimension selection visible

Digit keys now report unavailable nD navigation targets with an on-screen toast, while the dimension-sliders panel shows which non-displayed dimension the `[` and `]` keys currently control. Repeated stepping at a dimension bound also reports the minimum or maximum value reached. The help overlay and nD transform bench now make the navigable-subset numbering explicit, and the bench carries an exhaustive expected-value audit across every frame and channel.
