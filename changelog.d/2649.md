#### Gallery generation now audits built scenes

Gallery dataset generation now runs the built-scene auditors after generation
and reports the complete local inventory on every run. Missing or inconsistent
scene credits in newly generated stores fail the build; the full-inventory pass
and LOD-ladder findings remain report-only while the existing demo corpus is
laddered, so established neighbouring stores do not block gallery capture.
Auditor subprocesses are bounded and their diagnostics are flushed in execution
order.

The static aggregate already runs both auditors without arguments, so
`make check-all` can independently report or fail on locally built unladdered
stores even without this gallery-generation path; checkout-only CI has no built
demo stores to inspect.
