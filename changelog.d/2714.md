#### A touch panel for the kiosk, with no authoring required

`control.html` is a second page in the viewer bundle, meant for a tablet beside
a big display: a full-screen grid of chapter tiles, and tapping one jumps the
display to that stop of the tour. `luxar serve --control` prints both URLs.

It needs nothing added to a scene. A labelled dimension —
`Dimension(categories=[...])` — already carries the stop names, so the page asks
the viewer what dimensions it has and reads the labels that are there. Tours
built long before this page existed get a working menu against their existing
stores. Where a scene has no chapter dimension, or the page was opened with no
hub to talk to, it says so in words instead of drawing an empty grid.

The page is deliberately light: no renderer, no codecs, its own small
stylesheet. The build now checks that per page rather than globally — the viewer
may ship `three` as long as the WebGPU path stays lazy, while the panel may
reach neither, which is not something a source-level lint can see.

Two things an author can rely on. The tile classes, `data-*` state hooks and
`--luxar-control-*` custom properties are a styling contract, pinned by a test
from both the DOM and the stylesheet side, so a rename cannot quietly break a
scene's own CSS. And `?panel=<module>` loads an alternative panel, handed an
already-connected socket, for the exhibit that outgrows CSS — same-origin only,
since that module is executed.

#### A kiosk you can hand to an audience

The touch panel is now a full-page matrix of glass tiles that fits any screen
without scrolling, the scene can say how it reads, an unattended display can be
locked down, and an exported native app can host the relay itself.

The panel measures its own container and picks a grid, so ten to twelve
chapters land in a steady 4x3 on a landscape tablet and 3x4 in portrait —
checked at twelve sizes from 320x480 to 4K with no overflow in either axis.
Tiles are translucent over a slow aurora, and a partial final row sits centred
rather than trailing a hole. Labels size themselves against their own tile
rather than the viewport, because the cell shrinks as chapters are added.

`viewer_config.control_panel` adds a heading, per-chapter second lines, a pinned
column count, an idle reset and author CSS. Everything optional: a scene with no
block at all still gets the whole panel, derived from a discrete dimension's
`categories`. Both ESM protein tours are wired as the reference scenes, taking
their tile subtitles from the same `Story` table the waypoints are built from,
so the panel cannot drift from the tour. Author CSS is treated as hostile on the
`overlay_html` precedent: capped, injected as text, and stripped of `@import`
and remote `url()` — every remote URL in a stylesheet is also a beacon
reporting the kiosk's address to whoever hosts it.

`ui.kiosk` and `?kiosk` lock a display for public use: no panels, no keyboard,
no camera dragging, and optionally a watchdog that reloads only if WebGL
recovery has already had its chance. The URL flag can lock a store that predates
the block but deliberately cannot unlock one.

`luxar serve --host 0.0.0.0` also works properly now. It used to print
`http://0.0.0.0:5173` — a bind address no tablet can dial — and its data server
refused the viewer's own LAN origin, so the kiosk showed a blank screen with a
console full of CORS errors while `curl` read the data happily.

Demos keep remote control **off** unless asked: `luxar demo run <demo> --
--control [--control-token … --host 0.0.0.0]`.

#### An exported folder runs the kiosk too

`luxar export` has always copied the touch-panel page along with the viewer,
because both pages live in the same bundle — but the folder's generated
`serve.py` bound loopback, spoke no WebSocket and ran one request at a time, so
the *file* rode along while the *feature* did not. It does now:

    python serve.py --control --host 0.0.0.0 --control-token SECRET

Off by default, because a folder you double-click should not start listening
for anything that wants to drive it. The script prints a display URL and a
tablet URL, resolving a wildcard bind to a concrete address first — `0.0.0.0`
is a bind address, not a destination, and a URL containing it is one no tablet
can dial.

It is also threaded now, which is not a detail: a WebSocket occupies its thread
for as long as the kiosk runs, so on the old single-threaded server the first
attached panel would have blocked every later request, including the scene's
own chunks. A display that never finished loading would have been the visible
symptom.

The relay is the fourth implementation of one protocol, after the Python hub,
the viewer's client and the Go launcher's — and the only one that ships as a
copied file into artifacts nobody rebuilds, so it carries a copy of the
generated wire contract with a test pinning it to the source. It lives in
`luxar/cli/_export_serve_template.py` as a real module rather than a string
inside the exporter: ruff, mypy and the test suite all see it, and writing 600
lines of RFC 6455 framing inside an f-string (where every brace has to be
doubled) is not reviewable.

The folder's README now documents kiosk mode, says plainly that the token
travels in the URL and is therefore visible in the tablet's address bar, and
warns about `file://` for **both** pages rather than only `index.html` — the
touch panel is the more tempting one to double-click and fails the same way.

A mistyped token on the tablet now says so. The hub has always refused a bad
token, an unknown role or a foreign origin by accepting the handshake and then
closing it with a policy-violation code — precisely so the panel could tell
"no hub here" from "your token is wrong" — but the panel ignored the code: it
reported every refusal as "waiting for the display" and retried forever against
a hub that would refuse every attempt for the same reason. Found by opening the
page with a wrong token rather than by a test, and the first fix did not show
either, because the refused call's rejection painted over the message a
microtask later. The panel also no longer claims "connected, but no viewer has
attached yet" for failures that never said anything of the kind.
