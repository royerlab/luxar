#### Demo download credentials no longer follow unsafe redirects

`robust_download()` and `download_zip_member()` accepted arbitrary HTTP headers
for authenticated datasets. Requests already removed `Authorization` when a
redirect changed host, port, or downgraded HTTPS to HTTP, but custom credential
headers such as `api-key` kept following the redirect. Both download paths now
apply requests' own authorization policy to every caller-supplied header while
retaining its safe default-port HTTP-to-HTTPS upgrade exception.
