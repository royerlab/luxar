#### A refit no longer hands the scene a flat fit

`milkyway` and `cryoem_virus` write `levels` archives — four substitutive levels
each — and then returned the flat pre-LOD fit to the caller that builds the
scene. Their warm path loads the archive back and gets the levels, so only a
local refit (`--recompute`, or a machine without the precomputed archive) was
affected: it produced a flat single-leaf scene from the same code that produced
a `kind=lod` group on a later cache hit. Milkyway's display gain is documented
as calibrated against the finest level of that group.

Both now return what was STORED, the way `nexrad_supercell` already did and
documented: a re-read carries the levels (verified — four in, four out) and also
picks up the lossy cache encoding, so a cold run and a warm run agree on bytes
as well as topology rather than merely on splat count.

A gate covers the shape, because this is the third distinct way a topology can be
paid for and then discarded and the other two already have one. It fires only
where the return value can actually reach the scene as geometry, so a demo that
grafts the path with `add_gsplats_from_file` — cmu1 — is correctly left alone.
