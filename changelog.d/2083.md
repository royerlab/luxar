#### Restore demo destinations and robust grid fallback seeding

Paper and protein demos now preserve useful click-through when expensive cached
metadata predates stored identifiers. The arXiv landscape falls back to a
Google Scholar search on its hover label, while ESM3 searches UniProt with a
clean protein-name key that remains aligned with the displayed label. Real
accessions still deep-link to their exact UniProt entries; synthetic CAFA5
stand-ins remain unlinked rather than opening dead entry or search URLs.

Cosmicflows/Laniakea now carries each galaxy's Principal Galaxies Catalogue
number through the same spatial mask as its rendered data and links the point to
the corresponding NED object page.

Grid fallback seeding now preserves an empty Cartesian product's two-dimensional
shape on thin anisotropic volumes, then retries densely enough to fill the
requested seed count instead of failing late in a tiled fit.
