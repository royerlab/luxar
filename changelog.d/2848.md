#### Normalize uniform tile occupancy weighting

Normalize uniform-tile occupancy saturation by each tile's Hann-weighted voxel count, so homogeneous content receives the same splat density in folded or partial tiles of different sizes while preserving calibrated content-density saturation.

Resuming a batch planned with the previous occupancy law now warns that completed tiles retain their existing seed budgets and recommends `--no-resume` for a consistent refit.
