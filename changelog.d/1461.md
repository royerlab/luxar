#### The Gaia demo is now `gaia_milky_way`, and names the stars it marks

The demo's key was `galaxy`, which said nothing about Gaia and collided as a
substring with the two `spiral_galaxy` demos in every list and filter. It is now
`gaia_milky_way` — `luxar demo run gaia_milky_way`, output
`datasets/demos/gaia_milky_way.luxar.zarr`, and the same id in the gallery
manifest.

The three reference markers (Sun, Betelgeuse, Rigel) carry hover labels, and a
legend in the bottom-left corner names them with a colour swatch read from each
marker's own RGB, so the orientation cues are readable without hunting for a
tooltip. The star cloud's volumetric appearance was retuned as one set — opacity
0.5, absorption 0.12, intensity 0.175 — which keeps the disc translucent front to
back instead of hiding the far side of the bulge behind the near side.
