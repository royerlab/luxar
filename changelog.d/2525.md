#### The viewer's build and gate scripts are now linted, formatted and type-checked

`pnpm lint`, `pnpm format` and `pnpm typecheck` covered `src/` and nothing else, leaving
5,774 lines across 37 files — every Playwright config, both Vite configs, both Vitest
configs and every `.mjs` gate script — outside all three tools. The selection was
adverse: those are the scripts that enforce the other gates.

All three scopes now reach the package root, and a new `check-lint-scope` test fails
when a source file lands outside them again, so the gap cannot silently reopen.

Widening the scope found one dead setting and one type mismatch: `minWorkers` in the
Vitest config is not an option in Vitest 4, while a working GitHub reporter entry had
the wrong tuple type.
It also exposed that Playwright 1.62 honours the screenshot comparison's 10-second
runtime timeout without declaring that option in its public config type, and found five
`eslint-disable` directives in a benchmark script that had never suppressed anything,
because nothing had ever linted the file.

The coverage thresholds module now has declarations, so TypeScript consumers check
its exports and value shapes instead of importing them as `any`; the runtime slack
guard remains responsible for rejecting misspelled metric names.
