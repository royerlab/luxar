#### QEM mesh LOD now covers authored-size surfaces

The topology-preserving mesh decimator no longer runs an SVD for every candidate
edge, repeatedly filters face sets that already contain only active faces, or rebuilds
a complete collapse sequence for every LOD level. A QEM ladder now snapshots all
requested levels from one sequence while still aggregating colours and scalars from
the original vertices at each snapshot. On the worst-case open-annulus benchmark, a
complete three-level K=4 ladder takes 45.9 seconds at 9,882 vertices, so
`method="auto"` now selects QEM through 10,000 source vertices instead of 300 and
retains vectorized clustering above that measured envelope.
