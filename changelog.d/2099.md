#### Run external-reference audits before they quietly rot

Documentation links, demo click-through destinations, and the demo manifest's
Zenodo pins now share one weekly report. Each audit runs independently, maps its
result to `PASS`, `NOTICE`, `WARNING`, or `ERROR`, and contributes bounded,
escaped diagnostics to the GitHub job summary and visible run annotations.
Third-party outages and stale references stay visible without turning a
required merge check red.
