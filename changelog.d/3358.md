#### `LuxarLayer.setGain`: host brightness that does not change opacity

`setExposure` scales opacity, which in `volumetric` blending is optical depth, so a
host brightness slider above 1 made splats opaque instead of brighter. It also turned
the haze that the colour window maps to black into solid black discs, and soft
Gaussians into hard-edged ones. The new `setGain(gain)` / `getGain()` multiply the
post-colormap colour gain/offset pair instead. They brighten the emitted colour and
leave opacity and a colormapped node's scalar window alone, compose against the
authored values, and are re-applied as geometry streams in. The authored values are
kept in `userData`, so an LOD-fade clone does not apply the gain twice. Physical
meshes are left unchanged.
