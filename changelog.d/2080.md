#### Offset discrete dimensions navigate on their authored grid

Discrete scene dimensions now anchor snapping, keyboard navigation, animation,
and compiler validation at `range[0]` rather than zero. Mesh imports and inferred
nD gsplat dimensions also derive integer strides from coordinate differences, so
offset sequences such as 1/6/11 navigate directly without empty intermediate slices.
This changes existing stores whose declared minimum is off their data grid; recompile
them or move `range[0]` onto the authored grid before serving them with the new viewer.
