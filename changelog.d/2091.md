#### Demo link audits now verify the destinations demos actually emit

The opt-in `make check-demo-links` audit now derives public-page requests from the
same canonical registry enforced by the demo tests, so a path change cannot leave
the checker probing an obsolete URL. Destinations that need an official API still
request their canonical landing page first; the UniProt and USGS client-routed
shells answer 200 for arbitrary paths, so those requests confirm availability but
cannot prove the route is unchanged. Malformed registry entries are reported
separately from network outages, literal links are all probed, and dated human
checks become visibly stale after six months. The Gaia reference marker for the
Sun now opens NASA's solar record instead of a SIMBAD query that cannot resolve
solar-system objects.
