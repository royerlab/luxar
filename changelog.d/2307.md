#### Honor Cache Overrides for Line Admission

The `SceneLoader`'s session-scoped eager line-admission gate is now sized from
the same resolved cache pool the cache tiers use — explicit cache-pool override,
measured heap, device class, then fixed fallback — instead of the measured heap
alone. Safari and the native WKWebView launcher (no `performance.memory`) are
therefore no longer pinned to a 256 MiB line budget when a larger session budget
is configured with `?cacheBudgetMB=` or `LUXAR_CACHE_BUDGET_MB`.
