#### Repository gates now inspect their full intended scope

The documentation gate now scans nested Python and TypeScript modules, while
excluding test directories from API-documentation coverage. Demo-scene credit
and LOD checks gain `--require-scenes` for callers that expect built outputs and
no longer report a normal pass after inspecting nothing.

Python linting now covers the repository's scripts and support files, requires
Ruff formatting, and pins Ruff to the 0.16 series. Rust checks now propagate
Clippy failures. Wheel builds gain `hatch run check-wheel`, which verifies
package completeness, build exclusions, bundled viewer assets, Git LFS pointer
stubs, and PyPI's per-file size limit in both pull-request and release builds.
