#### Neuromast demo ships a tuned two-channel appearance

The 4D two-channel neuromast demo now composites both layers volumetrically with a
near-transparent optical depth (absorption 0.02), so the nuclei read inside the
membrane shell instead of both channels flattening additively, and each channel
carries its own display window and gamma (membranes 0.007–0.242 at gamma 1.67 and
half opacity; nuclei 0.025–0.719 at gamma 2.82). The windows are authored as
intensity/offset, which the viewer maps back to the window on a colormapped node.
Rebuilding the demo store is a scene compile only; no refit is involved.
