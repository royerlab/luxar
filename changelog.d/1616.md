#### Content-planned and batch fits share one physical normalization scale (#1616)

Content-planned and batch Gaussian-splat fits now use one shared raw-input normalization range across every box and sampled timepoint/channel. This keeps normalized convergence, seeding, culling, and amplitude limits consistent across spatial and temporal partitions without clipping peaks missed by bounded sampling.

Batch runs with denoising enabled do not automatically pin that raw sampled range: each task retains its existing denoise-aware range resolution, including its bounded-probe fallback. An explicit `norm_range` in the fit configuration remains an intentional override.

When a floor is applied, each child now uses `image_min = max(resolved_floor, shared_range_low)`. Because the low endpoint is shared, boxes above the pedestal no longer raise `image_min` to their own crop minima; `image_min == floor` whenever the shared low endpoint is at or below the resolved floor. This **supersedes the per-crop consequence** described in the #1174 fragment while preserving its clamp rule. The progressive fitter reaches the same result by handing pass 0 the whole-volume bounds shifted into the floor-subtracted basis, so it stops re-deriving the residual's own minimum after the pedestal was subtracted up front.

On the content path, because every box now carries a supplied range, the auto `amp_max` follows the normalized peak instead of capping at 1.0 (matching uniform tiling); this changes output amplitudes.

Calibration is unaffected: `gsplat cal` subtracts the floor from the volume once up front and forces `floor="none"` into every per-K fit (including the per-region-scale `--fit-exponent` sweep), so the changed normalization branch never runs there.
