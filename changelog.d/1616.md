#### Content-planned and batch fits share one physical normalization scale (#1616)

Content-planned and batch Gaussian-splat fits now use one shared raw-input normalization range across every box and sampled timepoint/channel, while a resolved background floor remains the physical zero point even for crops lying wholly above it. This keeps normalized convergence, seeding, culling, and amplitude limits consistent across spatial and temporal partitions without clipping peaks missed by bounded sampling.

`image_min` is now pinned to the resolved floor on every fit path — flat, progressive, uniform-tiled, and content — rather than being raised to a crop's own minimum. This **supersedes the interim rule** described in the #1174 fragment (`image_min = max(level, min(crop))`, under which a box above the pedestal subtracted its own minimum); with the pin, `image_min == floor` whenever suppression ran, on all paths. The progressive fitter reaches this by handing pass 0 a zero-pinned whole-volume `norm_range`, so it stops re-deriving the residual's own minimum after the pedestal was subtracted up front.

The change is not confined to the tiled paths. On a plain non-tiled `gsplat fit`, an explicit numeric `--floor N` sitting *below* the data minimum is now applied instead of silently ignored — which widens `intensity_range` and therefore coarsens the `max_abs_error = 1% of normalized range` convergence threshold — and `norm_percentile > 0` loses its low-end clipping when the floor sits under that percentile. On the content path, because every box now carries a supplied range, the auto `amp_max` follows the normalized peak instead of capping at 1.0 (matching uniform tiling); this changes output amplitudes.

Calibration is unaffected: `gsplat cal` subtracts the floor from the volume once up front and forces `floor="none"` into every per-K fit (including the per-region-scale `--fit-exponent` sweep), so the changed normalization branch never runs there.
