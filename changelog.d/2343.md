#### Visible Human cold fetch now verifies the path users take (#2343)

The Visible Human demo now resolves its fit and positional colors sidecar through
the manifest-backed loader instead of hand-copying cache and Git LFS files. Cold
fetch verification therefore covers the demo's real path, enforces both pinned
digests, and cannot green-light payload removal while users would still fall back
to the 1.1 GB source download and GPU refit.
