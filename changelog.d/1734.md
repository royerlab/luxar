#### The demo manifest records both copies of every archive

Every Zenodo-hosted demo archive has been refitted, re-encoded or rebuilt since
the manifest last recorded it, so the pins named files the deposition no longer
holds. A demo would have downloaded the current archive and then failed its own
integrity check.

Recording that truthfully used to be impossible without breaking the repository,
because one `sha256` field served two jobs — "what this repo ships" and "what the
record serves". They were identical by construction until a refit made them
differ. So a truthful hosted pin made the in-repo git-LFS fallback fail its own
checksum, which forced the payloads to be deleted in the same commit, which made
Zenodo the only source, which meant a human had to publish the records before
this change could merge at all.

The two contracts are now separate fields, so both are recorded and both are
true. 23 entries carry a genuine divergence — `sha256`/`bytes` describing the
copy in this repository and `hosted_sha256`/`hosted_bytes` the copy on the
record. Ten hosted-only files (both h2afva variants, the h2afva tp234 stack,
the four decimation cuts, drosophila, and both neuromast channels) have no local
copy for a second field to describe, so their single pin remains the hosted one.
Four entries whose repository and record copies agree carry no second field; an
equal pair contains no additional information.

Each hosted pin was derived from what the deposition holds rather than from a
build log — Zenodo reports an MD5 per file, and every pin comes from a copy whose
MD5 matches. DESI's was re-derived by hashing the hosted object directly, since
its chunk-layout rebuild had been uploaded but never pinned.

The in-repo payloads stay for now. Removing them is no longer entangled with
this change and lands separately.

The blastocyst keys and zebrafish archive have been updated on the draft records.
`scripts/zenodo_migration_audit.py --live` now reports that every pin matches;
publication remains a manual record-side step.
