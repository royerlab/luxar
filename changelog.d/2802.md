#### Linux native launchers now target WebKitGTK 4.1

Linux launcher builds now use the WebKitGTK 4.1 development and runtime ABI when
it is available, so they compile on current Ubuntu runner images and start on
4.1-only distributions such as Ubuntu 24.04. Development hosts carrying only
WebKitGTK 4.0 continue to build against it. A small pkg-config compatibility
module bridges the pinned `webview_go` binding's legacy 4.0 package name without
vendoring the dependency.
