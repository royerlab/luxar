#### Demo documentation counts now synchronize from their live sources

`hatch run sync-demo-counts` updates the four current documentation sites in
`README.md`, `CLAUDE.md`, and the Luxar visualization skill from the demo
registry and focused-example inventory. Historical changelog counts remain
untouched, and the README sample banner preserves its built and cached buckets
while assigning count changes to the not-generated bucket.

CI. The diff classifier now routes the root Claude guide and visualization skill
through that gate even when a change touches no Python file.
