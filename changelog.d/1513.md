#### Glass theme text clears WCAG AA over a bright scene

`frosted-glass` (the default theme) and `liquid-glass` both paint UI text over
a translucent dark panel tint, so the panel's actual on-screen color depends
on whatever scene the user has loaded behind it. Composited over the worst
case a scene can produce — pure white — frosted-glass's panel tint composited
to `#6b6d71`, giving primary/secondary/muted 4.88:1 / 3.73:1 / 2.56:1
(secondary and muted below WCAG AA's 4.5:1 floor for normal text, and muted
also below the 3:1 non-text floor for a meaning-bearing icon). Liquid-glass's
`::after` tint layer additionally carried a stray `opacity: 0.7` on top of its
own alpha, so its effective tint composited to `rgb(157)` and gave
primary/secondary/muted 2.61:1 / 2.19:1 / 1.73:1 — all three below AA, not
just secondary/muted.

Frosted-glass's panel tint (`background.secondary`) is raised from 0.65 to
0.75 alpha, and both themes' `text.secondary` (0.75 → 0.85) and `text.muted`
(0.5 → 0.72) alphas are raised alongside it — the panel tint and the text
alphas are independent knobs and both needed to move. Liquid-glass's panel
tint now lives in one place, a `--luxar-glass-tint` CSS custom property in
`liquid-glass.css` (raised 0.55 → 0.68), shared by the glass surface tint, the
recording indicator, the cursor-anchored context menus, the control-rail
tooltips, the control-rail first-run hint bubble, the recording confirmation
dialog, and the offline capture overlay (which all paint the same dark tint
for the same white-on-white — or, for the two modal surfaces, a too-light —
reason); the stray `opacity: 0.7`
multiplier on the `::after` layer is deleted so this alpha is the one
actually painted. Measured over the worst-case pure-white composite, both
themes now clear AA on all three text ranks: frosted-glass 6.8:1 / 5.8:1 /
4.7:1, liquid-glass 7.3:1 / 6.2:1 / 5.0:1 (primary / secondary / muted). The
dark-scene direction — already comfortable — is documented alongside these
numbers, though it isn't independently pinned: for white-ish text the
bright-scene case above is always the stricter one. A new unit test,
`tests/unit/themes/glass-contrast.test.ts`, pins these six numbers plus the
bright-scene rank ordering — and, for liquid-glass, the effective alpha
itself — so a future change to either theme's tint, text alphas, or a
reintroduced opacity multiplier cannot silently regress below AA again.
